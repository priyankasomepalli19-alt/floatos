FloatOS
========

A custom Bazzite-based Linux desktop distribution.

Design:
- Dark charcoal and black surfaces
- White typography
- Lime green accent (#A6FF4D)
- Papirus Dark icon theme
- KDE Plasma desktop

This image is built with BlueBuild from the Bazzite stable desktop base.
FloatOS preserves the Fedora/Bazzite OS identity fields needed by system tooling
while adding the FloatOS display name and variant metadata.
